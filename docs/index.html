Jarvis spricht direkt mit Claude. Dein Schlüssel bleibt lokal in deinem Browser (localStorage) und wird nur an Anthropic gesendet.

🔒 Sicherheit: Verwende diese Seite nur auf deinem eigenen Gerät. Der Key liegt unverschlüsselt im Browser. Ohne Key läuft Jarvis im eingeschränkten Demo-Modus.
